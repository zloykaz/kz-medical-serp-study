# Кто отвечает казахстанцу на медицинский вопрос в Google

Исследование для книги. Версия 2 методики — 30.10.2026, после независимой рецензии (review-1.md),
ДО получения выдачи. Частоты и подсказки Google Ads на этот момент уже получены — это раскрывается (п. 7).
Любое отступление после этой даты записывается в «Отступления» с причиной.

## 0. Раскрытие
Исследование делает команда медиагруппы, чьи сайты (tengrinews.kz, tengrihealth.kz и др.) могут попасть
в выдачу в категории «медиа». Поэтому: сайты автора показываются отдельной строкой, все доли считаются
с ними и без них.

## 1. Вопрос и гипотеза (числом, заранее)
Какие типы сайтов занимают выдачу Google в Казахстане по частым медицинским вопросам и какую долю
внимания получает каждый тип.
Гипотеза: доля фармы (категория 1 + связанные с производителем) по метрике 2 на запросах БЕЗ торговых
названий — меньше 5 %. Порог задан до данных. Результат публикуется в любом случае.

## 2. Совокупность запросов
Источники, у каждого запроса метка А / Б / оба:
- А. Ручной список 520 запросов (candidates_*.txt).
- Б. Подсказки Google Ads по 30 общим исходным словам (seeds.md).
Результат показывается и по всей совокупности, и только по Б (без влияния ручного списка).

Очистка — скриптом, правила заранее:
1. Склейка: только запросы с одинаковым набором лемм (порядок и формы слов не важны). Равная частота
   сама по себе не основание: Ads округляет частоты корзинами.
2. Отбор по смыслу — модели вслепую по одним правилам (поправка 1 от 30.10: основная модель размечает
   все запросы, вторая — случайные 20 %, seed = 20261030), каппа публикуется, расхождения решает человек.
   ВКЛЮЧАТЬ: симптом, болезнь, состояние, анализ и норма, лечение, препарат, прививка, контрацепция,
   побочные эффекты, совместимость, дозировка, «можно ли при беременности», обследования.
   ИСКЛЮЧАТЬ: поиск конкретной клиники/аптеки по названию или адресу, чистая покупка («купить», «цена»,
   «доставка», «рядом»), новости, ветеринария, косметика без медицинского вопроса, больничный, пособия,
   ОСМС и право на бесплатные лекарства (это право, а не медицина).
3. Многозначные запросы («давление», «температура», «қысым»): остаются, только если в топ-10 не меньше
   половины медицинских результатов (проверяется по снимку).
4. Частота 0 или нет данных — исключаются, НО число исключённых публикуется по группам с примерами:
   Google скрывает частоты чувствительных тем.

## 3. Выборки
- Основная: 300 самых частых запросов после очистки.
- Слой торговых названий: запросы с названием препарата (нурофен, кагоцел…) — отдельный слой.
  ГЛАВНАЯ цифра доли фармы — по запросам без торговых названий; цифра с ними — рядом.
- Проверочная: 100 случайных из остальной совокупности (частота от 50/мес), seed = 20261030.
  Проверяет «частые против хвоста», а не представительность совокупности (ограничение, п. 8).

## 4. Выдача
- google.kz, Казахстан (2398), телефон, обычные результаты: тип organic, позиции по rank_group 1–10;
  избранный фрагмент — не в топ-10, отдельно.
- Язык интерфейса: ru для русских запросов, kk для казахских (не примет — ru, запись в «Отступления»).
- Три снимка: день 1, день 2, день 14, каждый — в один и тот же час; время снимка записывается.
- Ответ ИИ, избранный фрагмент, «Похожие вопросы», видео, карусель новостей, реклама: наличие по запросу;
  домены из ссылок ответа ИИ и избранного фрагмента и рекламодатели размечаются той же книгой
  и считаются отдельными метриками (если API отдаёт ссылки ответа ИИ — проверить на первом снимке).

## 5. Разметка (кодовая книга — codebook.md)
- Категорию ставят по свидетельствам со страницы (подвал, юрлицо, «О нас», «при поддержке»), а не по
  памяти модели; ссылка на свидетельство хранится в разметке.
- Признаки рядом с категорией: связь с производителем (собственность / спонсорство / нет / не определено),
  собственность (государственная / частная), страна (юрлицо важнее домена; нет юрлица — «не определено»),
  платформа (YouTube, Instagram, Дзен, Telegram, Kaspi и т. п. — тогда категория по автору канала/продавцу).
- Надёжность: две модели вслепую; человек проверяет ВСЕ домены, дающие в сумме 80 % внимания (метрика 2),
  и 10 % остальных; второй человек слепо размечает 50 доменов. Согласие — по каждой категории.
- Модели, версии, промпты и температура публикуются.

Скрытое присутствие фармы — выборка 200 адресов из всех категорий, кроме фармы, пропорционально
метрике 2. Три уровня: (1) помеченная реклама/партнёрский материал; (2) торговое название со ссылкой
на производителя или его сайт; (3) торговое название без пометки. Публикуются отдельно, с фармой не смешиваются.

## 6. Подсчёт
- Метрика 1: доля мест в топ-10 по категориям; отдельно топ-3.
- Метрика 2 (внимание): место весит «частота × вес позиции». Три набора весов, все заранее:
  (а) измеренная кривая CTR: Казахстан, телефон, медицинские запросы (ctr_curves.md — источник, таблица
      и почему не публичная кривая США); (б) позиции 1–3 = 1, 4–10 = 0,5; (в) все 10 позиций равны.
  Вывод считается устойчивым, только если он одинаков при всех трёх.
- Чувствительность: то же по запросам без блоков над выдачей (ответ ИИ, реклама, избранный фрагмент).
- Неопределённость: двухуровневый бутстреп (запросы, затем снимок внутри запроса), 10 000 повторов, 95 %.
- Разрезы: без торговых названий / с ними; симптомы / препараты; русский / казахский; основная /
  проверочная; только источник Б; с сайтами автора / без; казахстанские / иностранные сайты.

## 7. Что получено на 30.10 (до выдачи)
- Частоты 520 запросов ручного списка.
- Подсказки по 20 русским исходным словам — 21 824 запроса; по 10 казахским — 34.
- Объединение — 22 286 уникальных запросов, 6 261 с частотой от 50 в месяц.
- Уже видно: верх спроса — названия препаратов. Поэтому слой «названия препаратов» разбит на два:
  торговое название (нурофен) и международное непатентованное (ибупрофен). Главная цифра доли фармы
  считается без запросов с ТОРГОВЫМ названием; вариант «без любых названий препаратов» — рядом.
- Казахская часть совокупности мала уже на входе — свойство данных Google Ads, пишется в п. 8.

## 8. Ограничения (в книге — рядом с цифрами)
- Только Google; Яндекс в Казахстане заметен и не измерялся. ИИ-ассистенты не измерялись.
- Отбор по среднегодовой частоте от сезона не зависит, а содержимое выдачи — зависит: снимки в
  октябре–ноябре (начало сезона простуд, новости о гриппе).
- Совокупность задана ручным списком и 30 исходными словами — запросы вне их охвата не представлены.
- Одна точка «Казахстан», телефон; без разницы по городам.
- Частоты Ads округлены и сгруппированы — порядок величины.
- Казахских запросов мало в данных Ads; казахская выдача — с широким интервалом.
- Отбор запросов по смыслу: 80 % размечены одной моделью; ошибка оценивается по проверочным 20 %.

## 9. Воспроизводимость
Публикуются: запросы с частотами и метками источника, исключённые с причинами, сырые ответы выдачи,
кодовая книга, разметка с доказательствами, промпты, скрипт подсчёта. Методика получает внешнюю
метку времени до первого снимка выдачи (решение владельца: OSF или публичный репозиторий).

## Поправки до первого снимка выдачи
1. 30.10.2026, разметка запросов (п. 2.2). Пилот: 240 случайных запросов из 6 261 (seed 20261030), по
   две модели в каждом варианте, temperature 0, один промпт (label_queries.py).
   - С рассуждением: deepseek-v4.1-flash и qwen3.8-flash — каппа medical 1,00, group 0,89, drug 0,99,
     lang 1,00; 150–190 токенов ответа на запрос.
   - Без рассуждения: в 15 раз меньше токенов, каппа medical 0,46–0,82, drug 0,65–0,68 — не годится.
   - qwen3.8-max не закончила ни одной пачки за 15 минут — исключена.
   Решение: deepseek-v4.1-flash с рассуждением размечает все 6 261 запрос, qwen3.8-flash с рассуждением
   вслепую — случайные 20 % (1 252, seed 20261030, файл check20.csv); согласие считается на них,
   все расхождения на них решает человек. Причина — расход токенов при полном согласии моделей на пилоте.
   Ограничение: на 80 % запросов разметка одной модели без второй проверки (пишется в п. 8).
